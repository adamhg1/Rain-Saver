Science Fair Project

A sensor-controlled, gravity-fed plant watering system using collected rainwater

An Arduino measures soil moisture and opens a 12 V valve only when the plant needs water. The water comes from a raised rain bucket, so no tap water and no pump are used.

01

Purpose

Garden plants are often watered on a fixed schedule with treated drinking water, whether the soil needs it or not. This wastes water and can over-water the roots. This project tests whether a simple automated system can keep soil moisture in a healthy range using only rainwater.

Question

Can a sensor-controlled, gravity-fed system keep a potted plant's soil moisture between 35 % and 60 % using only collected rainwater?

Hypothesis

If the valve opens only when the soil drops below 35 % and closes once it reaches 60 %, then the soil will stay in that range while using less water than watering on a fixed schedule.

Variables

Independent

Whether watering is automatic (sensor-controlled) or done on a fixed schedule.

Dependent

Soil moisture (%) over time, and total litres of water used.

Controlled

Plant type, pot size, soil type, location, bucket height, and tube length.

02

System design

The system has two separate paths: a water path driven by gravity, and an electrical control path that decides when the valve is open.

05

Method

  1. Calibrate the sensor. Record the raw reading in dry soil and in water. Enter these values as DRY_VALUE and WET_VALUE so readings convert to 0–100 %.
  2. Test the valve. With the bucket filled and raised, run a 10-second valve test and measure the supply voltage while the valve is open (target ≥ 11 V).
  3. Check for leaks. Run water through every connection and tighten clamps where needed.
  4. Run the automatic system. Start with dry soil. Log moisture every 5 s through the Serial Monitor.
  5. Run a comparison. Water an identical pot on a fixed schedule and record the volume used.
  6. Analyse. Graph moisture over time for both pots and compare total water used.
06

Safety and failure handling

RiskControl in the design
Valve coil overheatingEach pulse is limited to 30 s, followed by a 60 s cool-down. Maximum 6 pulses per session, then a 10-minute rest.
Empty bucketIf 4 pulses in a row raise moisture by less than 2 %, the system locks out and stops watering until reset.
Loose sensor wireReadings outside the valid range (below 50 or above 1000 raw) trigger a lockout instead of watering.
Over-wateringWatering stops as soon as moisture reaches 60 %. The valve fails closed if power is lost.
Water near electricityOnly 5 V and 12 V DC near the water. Electronics are in a sealed box above the pot, and the wall adapter is kept dry and away from the setup.
Valve opening at startupThe relay pin is set to OFF before it is enabled, so the valve cannot open during power-up.

Arduino code

Upload with the Arduino IDE (board: Arduino Uno). Open the Serial Monitor at 9600 baud. Each line is comma-separated, so it can be pasted straight into a spreadsheet.

auto_waterer.ino
/*
  AUTOMATIC PLANT WATERER - Arduino Uno
  =====================================
  Rain bucket (raised) -> bulkhead -> vinyl tube -> brass barb
  -> 12V solenoid valve -> brass barb -> vinyl tube -> plant pot

  PARTS
    Valve:    U.S. Solid USS2-00069, 1/2", 12V DC, normally closed
              about 20 W = about 1.7 A. Gets hot, so it must NOT stay on.
    Power:    12V 2A adapter -> barrel jack screw terminal
    Relay:    5V relay module
    Diode:    1N4007 across the valve (flyback protection)
    Sensor:   soil moisture sensor (analog)

  WIRING
    Sensor   VCC -> pin 8 (only powered while reading, slows corrosion)
             GND -> GND      AOUT -> A0
    Relay    IN  -> pin 7    VCC -> 5V    GND -> GND
    Valve    12V + -> relay COM
             relay NO -> valve wire A  (call this one +)
             valve wire B -> 12V -
             1N4007 across valve wires, STRIPE toward valve wire A (+)
    Both GNDs (Arduino and 12V -) do NOT need to connect; the relay
    keeps the 12V side separate.

  SAFETY FEATURES
    - Valve open 30 s max per pulse, then 60 s soak/cool-down
    - Max 6 pulses per session (3 min total), then 10 min rest
    - Lockout if 4 pulses don't make the soil wetter (empty bucket)
    - Lockout if the sensor reading is impossible (loose wire)
    - Valve forced closed at startup

  SERIAL MONITOR (9600 baud) - type a letter and press Enter
    t = valve TEST: opens 10 s (sink test / measure adapter voltage)
    w = water now (one pulse)
    s = stop watering now
    c = calibration mode (raw numbers every second)
    n = back to normal mode
    r = reset after a lockout
    ? = show settings
*/

// ================= SETTINGS YOU CAN CHANGE =================

const byte SOIL_PIN         = A0;
const byte SENSOR_POWER_PIN = 8;
const byte RELAY_PIN        = 7;
const byte LED_PIN          = LED_BUILTIN;   // pin 13 light on the board

// Most relay modules switch ON with LOW. If the valve is open when it
// should be closed, change this to false.
const bool RELAY_ACTIVE_LOW = true;

// Calibration: type c, then write down the raw numbers.
const int DRY_VALUE = 520;   // sensor in dry garden soil
const int WET_VALUE = 260;   // sensor in a cup of water

// Moisture targets (percent)
const int START_WATERING_BELOW = 35;
const int STOP_WATERING_AT     = 60;

// Timing
const unsigned long MAX_PULSE_MS  = 30UL * 1000;       // 30 s valve open max
const unsigned long SOAK_MS       = 60UL * 1000;       // 60 s soak + cool coil
const unsigned long REST_MS       = 10UL * 60 * 1000;  // 10 min between sessions
const unsigned long TEST_MS       = 10UL * 1000;       // t command
const unsigned long READ_EVERY_MS = 5UL * 1000;        // log every 5 s

// Safety limits
const byte MAX_PULSES_PER_SESSION = 6;
const byte MAX_PULSES_NO_CHANGE   = 4;
const int  MIN_RISE_PERCENT       = 2;
const int  SENSOR_MIN_VALID       = 50;
const int  SENSOR_MAX_VALID       = 1000;

// ===========================================================

enum State { IDLE, WATERING, SOAKING, RESTING, TESTING, LOCKOUT, CALIBRATE };
State state = IDLE;

unsigned long stateStart  = 0;
unsigned long lastRead    = 0;
unsigned long lastLed     = 0;
unsigned long totalOpenMs = 0;

int  rawValue = 0;
int  moisture = 0;
int  moistureAtPulse = 0;
byte pulsesThisSession = 0;
byte pulsesNoChange = 0;
bool valveOpen = false;
bool ledOn = false;

const char* stateName(State s) {
  switch (s) {
    case IDLE:      return "IDLE";
    case WATERING:  return "WATERING";
    case SOAKING:   return "SOAKING";
    case RESTING:   return "RESTING";
    case TESTING:   return "TESTING";
    case LOCKOUT:   return "LOCKOUT";
    case CALIBRATE: return "CALIBRATE";
  }
  return "?";
}

// ---------------- Valve ----------------
void setValve(bool open) {
  if (open == valveOpen) return;
  if (!open) totalOpenMs += millis() - stateStart;
  valveOpen = open;
  bool level = RELAY_ACTIVE_LOW ? !open : open;
  digitalWrite(RELAY_PIN, level ? HIGH : LOW);
}

// ---------------- Sensor ----------------
int readSoilRaw() {
  digitalWrite(SENSOR_POWER_PIN, HIGH);
  delay(10);
  const byte N = 10;
  int s[N];
  for (byte i = 0; i < N; i++) { s[i] = analogRead(SOIL_PIN); delay(2); }
  digitalWrite(SENSOR_POWER_PIN, LOW);

  // sort, then average the middle 6 (drops 2 highest + 2 lowest)
  for (byte i = 1; i < N; i++) {
    int key = s[i]; int j = i - 1;
    while (j >= 0 && s[j] > key) { s[j + 1] = s[j]; j--; }
    s[j + 1] = key;
  }
  long sum = 0;
  for (byte i = 2; i < N - 2; i++) sum += s[i];
  return sum / (N - 4);
}

int rawToPercent(int raw) {
  long pct = map(raw, DRY_VALUE, WET_VALUE, 0, 100);
  return constrain(pct, 0, 100);
}

// ---------------- States ----------------
void enterState(State s) {
  setValve(false);                 // close first, always
  state = s;
  stateStart = millis();
  if (s == WATERING) {
    moistureAtPulse = moisture;
    pulsesThisSession++;
    setValve(true);
  }
  if (s == TESTING) setValve(true);
  Serial.print(F("# -> "));
  Serial.println(stateName(s));
}

void lockout(const __FlashStringHelper* why) {
  enterState(LOCKOUT);
  Serial.print(F("# SAFETY LOCKOUT: "));
  Serial.println(why);
  Serial.println(F("# Fix it, then type r"));
}

void startSession() {
  pulsesThisSession = 0;
  pulsesNoChange = 0;
  enterState(WATERING);
}

void endSession() { enterState(RESTING); }

// ---------------- Logging ----------------
void printHeader() {
  Serial.println(F("time_s,raw,moisture_pct,state,valve,total_open_s"));
}

void logLine() {
  Serial.print(millis() / 1000);   Serial.print(',');
  Serial.print(rawValue);          Serial.print(',');
  Serial.print(moisture);          Serial.print(',');
  Serial.print(stateName(state));  Serial.print(',');
  Serial.print(valveOpen ? 1 : 0); Serial.print(',');
  Serial.println(totalOpenMs / 1000);
}

void printSettings() {
  Serial.println(F("# ---- Settings ----"));
  Serial.print(F("# Dry raw / Wet raw: ")); Serial.print(DRY_VALUE);
  Serial.print(F(" / "));                    Serial.println(WET_VALUE);
  Serial.print(F("# Water below / stop at %: ")); Serial.print(START_WATERING_BELOW);
  Serial.print(F(" / "));                          Serial.println(STOP_WATERING_AT);
  Serial.print(F("# Pulse s / Soak s: ")); Serial.print(MAX_PULSE_MS / 1000);
  Serial.print(F(" / "));                  Serial.println(SOAK_MS / 1000);
  Serial.print(F("# Max pulses per session: ")); Serial.println(MAX_PULSES_PER_SESSION);
  Serial.print(F("# Rest min: ")); Serial.println(REST_MS / 60000);
}

// ---------------- Commands ----------------
void handleSerial() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c >= 'A' && c <= 'Z') c += 32;   // accept capitals
    switch (c) {
      case 't':
        if (state == LOCKOUT) { Serial.println(F("# Locked out. Type r first.")); break; }
        Serial.println(F("# VALVE TEST 10 s - measure adapter voltage now (want 11V+)"));
        enterState(TESTING);
        break;
      case 'w':
        if (state == LOCKOUT) { Serial.println(F("# Locked out. Type r first.")); break; }
        Serial.println(F("# Manual watering"));
        startSession();
        break;
      case 's':
        Serial.println(F("# Stopped"));
        endSession();
        break;
      case 'c':
        Serial.println(F("# CALIBRATE: dry soil, then cup of water. Write down raw numbers."));
        enterState(CALIBRATE);
        break;
      case 'n':
        printHeader();
        enterState(IDLE);
        break;
      case 'r':
        Serial.println(F("# Reset"));
        enterState(IDLE);
        break;
      case '?':
        printSettings();
        break;
    }
  }
}

// ---------------- LED ----------------
// off = waiting, solid = valve open, slow blink = soak/rest,
// fast blink = LOCKOUT (needs you), very slow = calibrate
void updateLed() {
  unsigned long period;
  switch (state) {
    case IDLE:      digitalWrite(LED_PIN, LOW);  return;
    case WATERING:
    case TESTING:   digitalWrite(LED_PIN, HIGH); return;
    case LOCKOUT:   period = 150;  break;
    case CALIBRATE: period = 1500; break;
    default:        period = 700;  break;
  }
  if (millis() - lastLed >= period) {
    lastLed = millis();
    ledOn = !ledOn;
    digitalWrite(LED_PIN, ledOn ? HIGH : LOW);
  }
}

// =========================================================
void setup() {
  // Relay OFF before the pin becomes an output -> no click at startup
  digitalWrite(RELAY_PIN, RELAY_ACTIVE_LOW ? HIGH : LOW);
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(SENSOR_POWER_PIN, OUTPUT);
  digitalWrite(SENSOR_POWER_PIN, LOW);
  pinMode(LED_PIN, OUTPUT);

  Serial.begin(9600);
  Serial.println(F("# Automatic Plant Waterer ready. Type ? for settings."));
  printSettings();
  printHeader();

  rawValue = readSoilRaw();
  moisture = rawToPercent(rawValue);
  enterState(IDLE);
}

void loop() {
  unsigned long now = millis();
  handleSerial();
  updateLed();

  // ---- Calibration: raw numbers every second ----
  if (state == CALIBRATE) {
    if (now - lastRead >= 1000) {
      lastRead = now;
      rawValue = readSoilRaw();
      Serial.print(F("raw="));       Serial.print(rawValue);
      Serial.print(F("  moisture%=")); Serial.println(rawToPercent(rawValue));
    }
    return;
  }

  // ---- Timers that must run right away (not every 5 s) ----
  if (state == TESTING && now - stateStart >= TEST_MS) {
    Serial.println(F("# Test done. Did it click firmly and flow well? Log it!"));
    enterState(IDLE);
  }
  if (state == WATERING && now - stateStart >= MAX_PULSE_MS) {
    enterState(SOAKING);           // hard 30 s limit
  }

  // ---- Read + log every 5 s ----
  if (now - lastRead < READ_EVERY_MS) return;
  lastRead = now;
  rawValue = readSoilRaw();
  moisture = rawToPercent(rawValue);
  logLine();

  if (state == LOCKOUT || state == TESTING) return;

  if (rawValue < SENSOR_MIN_VALID || rawValue > SENSOR_MAX_VALID) {
    lockout(F("sensor reading out of range - check sensor wires"));
    return;
  }

  switch (state) {
    case IDLE:
      if (moisture < START_WATERING_BELOW) startSession();
      break;

    case WATERING:
      if (moisture >= STOP_WATERING_AT) endSession();
      break;

    case SOAKING:
      if (now - stateStart < SOAK_MS) break;

      if (moisture >= STOP_WATERING_AT) {
        Serial.println(F("# Soil is wet enough"));
        endSession();
        break;
      }
      if (moisture - moistureAtPulse >= MIN_RISE_PERCENT) {
        pulsesNoChange = 0;
      } else {
        pulsesNoChange++;
        Serial.print(F("# Pulse did nothing ("));
        Serial.print(pulsesNoChange); Serial.print('/');
        Serial.print(MAX_PULSES_NO_CHANGE); Serial.println(')');
      }
      if (pulsesNoChange >= MAX_PULSES_NO_CHANGE) {
        lockout(F("moisture not rising - bucket empty or tube blocked?"));
      } else if (pulsesThisSession >= MAX_PULSES_PER_SESSION) {
        Serial.println(F("# Max pulses reached - resting so the valve cools"));
        endSession();
      } else {
        enterState(WATERING);
      }
      break;

    case RESTING:
      if (now - stateStart >= REST_MS) enterState(IDLE);
      break;

    default:
      break;
  }
}
